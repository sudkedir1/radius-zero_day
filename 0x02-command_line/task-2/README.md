we've been working through a lot of commands for managing and manipulating the files such as creating removing moving renaming and so on 

***copy
------to copy a file we use a "cp" 

for example Copy notes.txt into the backup directory:

cp practice/file-lab/documents/notes.txt practice/file-lab/backup/


**moving

eg,  Move draft.txt into the documents directory:

mv practice/file-lab/drafts/draft.txt practice/file-lab/documents/

***removing

Code
